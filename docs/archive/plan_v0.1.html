결론

A팀은 앞, B팀은 뒤

교수님 조언도 같았음. C 공정이 이미 정해져 있으면 앞뒤로 붙이는 게 제일 낫다고.

풀 문제

C는 검사하고 조립만 함

편차 큰 셀이 한 팩에 섞이고, 조립 뒤에 생기는 불량은 못 잡음. 실물로 못 붙이는 앞뒤 공정을 트윈으로 붙여서 줄이기.

팀문제전 → 후 비교수치 근거
A · 전공정매칭 없이 온 순서대로 넣어서 팩 안 셀 전압 편차가 큼무작위 투입 vs 등급별 4셀 세트 → 팩 내 편차(mV)실측
B · 후공정조립 직후에만 검사해서 보관 중 자가방전 불량이 그대로 나감재검사 없음 vs 보관 후 재검사 → 검출률주입값
B · 후공정보관 시간 못 채운 팩이 나가거나 오래된 팩이 남음랙 배정 방식 2종 → 입출고 시간규칙 구현
공통분류 설비도 창고도 없는데 제어 로직은 미리 검증해야 함실물 없이 잡은 로직 오류 수, 시나리오별 통과 여부우리 상황 그대로

공정 문제로 "왜 이 공정을 붙였나"를 설명하고, 로직 사전 검증으로 "트윈이 뭘 해 줬나"에 답하기. 후공정 자가방전은 우리가 넣은 불량을 우리가 잡는 구조라 발표 때 먼저 밝히기.

A팀 · 전공정

셀이 로봇 앞에 오기 전까지

C 설계에 빠져 있던 매칭이 여기서 채워짐. C가 4셀 팩이라 세트 공급이 바로 이어짐.

분류만 하면 Factory I/O 기본 예제로 보이고 4명 일도 모자람. 세트 공급과 C 연결까지 가야 함. 이 추적 로직은 C의 슬롯 이력과 같은 구조라 C로 그대로 넘어감.

내부저항은 지금 C 1차 검사가 안 재는 값. 가상 값으로 넣을지, C 검사기에 측정을 추가할지 정해야 함. 가상 값이면 수치 근거가 "주입값"으로 내려감.

A팀 · 디스코드 논의

팀에서 나온 주제 3개는 한 라인의 층

서로 다른 주제가 아니라 같은 전공정 라인에 차례로 얹히는 것들. 아래부터 쌓으면 중간에 끊겨도 결과물이 남음.

1층 · 뼈대 셀 입고검사 · LOT 추적 · NG 분리 셀 제조사에서 팩 조립공장으로 넘어오는 경계 공정. 센서 · 컨베이어 · 푸셔 · PLC · 화면이 자연스럽게 엮이고, C와는 "정상 4셀 세트 공급"으로 이어짐
2층 · 차별점 특성 매칭 4셀 공급 + LOT 이상 보류 전압 · 내부저항으로 분류하고 비슷한 4개를 묶기. 특정 LOT에서 NG가 반복되면 그 LOT만 공급 보류
3층 · 여유 있으면 공급 지연 대응 버퍼 제어 병목 · 대기 · 가동률을 수치로 보이기 쉬움. 2층이 돌고 나서
  • 전압만 같은 것과 특성이 비슷한 것은 다름실제 셀 검사는 전압과 내부저항을 같이 봄. 분류 기준도 둘 다로
  • 조립설비 업체 사례 (팀원 조사)앞단에서 검사 · 선별 후 바로 조립. 장기 보관이나 이송 때 재검사. ID · LOT 불일치나 검사 이력 없으면 보류. 인용 전 출처 확인
  • 보관 전후 자가방전 비교나온 아이디어인데 B팀 출고검사와 겹침. A에서 할지 B로 넘길지 정하기
