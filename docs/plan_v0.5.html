1. 프로젝트 개요

1) 추진 배경과 해결할 문제

기존 C 라인의 계획은 18650 셀의 전압을 검사하여 불합격 셀을 분리하고, 합격 셀을 들어온 순서대로 팩에 투입하는 방식임. 합격 셀끼리도 전압 차이가 남을 수 있으므로, 합격 여부를 판정하는 검사와 특성이 비슷한 셀을 묶는 공급 공정을 구분하여 설계할 필요가 있음.

A팀은 C 앞단에 입고검사, LOT 추적, NG 분리, 등급별 버퍼 및 4셀 세트 공급 공정을 가상으로 구성함. 같은 셀 데이터를 순서대로 묶는 방식과 등급별로 묶는 방식을 비교하여 세트 내 전압 편차의 변화를 평가하고, 실물 설비를 추가하기 전에 분류 순서와 공급 인터록을 검증하는 것을 목표로 함.

A팀의 직접 구현 범위는 가상 전공정과 그 제어·이력 관리임. 실물 C의 로봇 제어 및 B팀의 후공정은 각 담당 범위로 두고, 공용 태그와 ID 규칙 및 신호 교환 조건을 공동으로 확정함.

3) 실물 데이터와 가상 검증의 연결

실물 셀의 전압을 측정하여 가상 셀 데이터에 연결하고, 그 분포에 맞춰 등급 구간을 설정함. 가상 전공정에서 분류 및 공급 조건을 시험한 뒤 검증한 조건을 C 연계 제어에 반영할 계획임. 실측값은 사전 입력과 통신 수신 중 확보 가능한 방식으로 연결하며, 실시간 자동 연동 여부는 통신 구성 확정 시 구분하여 기록함.

내부저항은 측정 가능 여부를 먼저 확인함. 전압만 확보한 경우 평가 범위는 세트 내 전압 편차로 한정하며, 팩 수명이나 실제 불량률 개선을 달성한 것으로 해석하지 않음.

2) 전압 편차 비교 방법

세트 편차(mV) = 세트 내 최대 전압 - 최소 전압
감소율(%) = (순서별 평균 편차 - 등급별 평균 편차) ÷ 순서별 평균 편차 × 100

두 방식에 같은 합격 셀 데이터와 검사 기준을 적용하고, 입력 순서·등급 구간·비교 세트 수를 기록함. 등급별로 4개를 채우지 못한 잔여 셀은 별도로 집계하여 비교에서 빠진 수량을 밝힘. 순서별 평균 편차가 0이면 감소율을 계산하지 않고 두 방식의 편차를 그대로 제시함.

① 셀 입고 및 검사

이전 셀의 분류가 끝난 뒤 다음 셀을 투입함. 검사 위치 도착 시 셀 ID와 LOT에 검사 데이터를 연결하여 판정함. 전압·내부저항의 적용 범위와 NG 및 등급 구간은 실측 가능 항목과 데이터 분포를 확인한 뒤 확정함. 목적지 레인에 수용 여유가 있을 때 검사 위치 블레이드를 해제함.

② NG 분리 및 등급 분류

전압 미달, 저항 초과, LOT 미판독 또는 보류 LOT는 NG 경로로 배출함. 합격 셀은 A·B·C 레인으로 분류하고 푸셔 전진 및 복귀 끝 센서로 동작 완료를 확인함. 푸셔가 미는 동안 메인 컨베이어를 정지함.

③ 버퍼 및 세트 공급

각 레인은 예약 수와 분류 완료 재고를 관리함. 같은 등급의 셀 4개가 모이고 C가 투입 가능한 경우 한 레인씩 배출함. 공급 완료는 실제 배출 수량, 출구 감지 및 C 수신 확인으로 판정하도록 설계함. 세트 ID와 구성 셀 ID 4개를 연결하여 중복 공급과 이력 누락을 확인함.

④ 이상 정지 및 복구

비상정지, 미도착, 검사 위치 미출발, 분류 및 공급 시간 초과를 감시함. 이상 해제 후에는 가상 부품의 위치와 내부 재고를 대조하고, 재시작 시 중복 투입이나 재고 불일치가 없는지 시험함.

(4) 현재 상태 및 검증 계획

2026년 11월 17일 기록 기준, 임시 검사값을 사용하는 소프트 PLC 시연에서 씬 로드·통신·분류 동작을 관찰함. 4셀 공급은 통합 시험 보완이 필요하며, 실물 PLC 연계와 수집기·DB·조회 화면은 후속 개발 범위임.
