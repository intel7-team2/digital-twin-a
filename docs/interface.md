# 2A 인터페이스 (PLC ↔ Python ↔ Factory I/O)

초안. PLC 팀이랑 맞추려고 만든 문서. 숫자는 협의 전 제안값.

## 기준

- PLC 디바이스 대역 1차 협의 (11/18, 디스코드)
  - 로봇 프로젝트 0~1999
  - **디지털트윈 2A 2000~2999**
  - 디지털트윈 2B 3000~3999
- 확인 필요: M·D만 해당인지, T·C·X·Y도 같은 번호 대역인지

## 연결 구조

```
Factory I/O ──Modbus TCP── Python 브리지 ──MX Component── GX Simulator2 (래더)
 (Client)                    (Server 127.0.0.1:502)
                               └─ 값 생성기, DB 수집기도 같은 프로세스
```

- GX Simulator2는 외부 네트워크가 없어서 Factory I/O가 직접 못 붙음. 브리지가 중간에서 복사함.
- Factory I/O 쪽 설정은 지금 시연(softplc.py)이랑 같음. Modbus TCP Client → 127.0.0.1:502.
- **PLC에 쓰는 Python 프로그램은 브리지 하나만.** 값 생성기, SCADA 쓰기도 브리지를 거침.
- MX Component 버전 확인 필요. v4면 32비트 Python이 필요할 수 있음.

| M2200~M2249 | PLC → Python 신호 | PLC |
| M2250~M2299 | Python → PLC 신호 | 브리지 |

| D2000~D2099 | Factory I/O 워드 입력 (D2000 = LOT 비전) | 브리지 |
| D2100~D2199 | 측정값 | 브리지 (값 생성기) |
| D2200~D2299 | 판정 기준값 | 브리지 (SCADA에서 변경) |
| D2300~D2399 | 판정 결과 | PLC |

## 측정값 블록 (D2100~)

단위는 전부 정수. mV, mA, mΩ.

| 디바이스 | 내용 | 예 |
|---|---|---|
| D2100~D2101 | 셀 ID (32비트, 하위 워드 먼저) | 1001 |
| D2102 | LOT 코드 | 1 / 4 / 7 |
| D2103 | OCV [mV] | 3685 |
| D2104 | V1 [mV], 0.2C 10초 끝 | 3670 |
| D2105 | I1 [mA] | 600 |
| D2106 | V2 [mV], 1C 1초 끝 | 3610 |
| D2107 | I2 [mA] | 3000 |
| D2108 | 방향 (1 = +극 위, 2 = −극 위, 0 = 미판독) | 1 |
| D2109 | 읽기 상태 (0 정상, 1 QR 미판독, 2 측정 실패) | 0 |
| D2110 | 전송 번호 (보낼 때마다 +1) | 37 |

- 셀 ID = 비전 감지 순간 값 생성기가 붙이는 일련번호. QR 리더 대역(에뮬레이션)임.
- 실제 라인에선 QR 리더·측정기가 같은 디바이스에 쓰면 됨. 래더는 그대로.

## 측정 핸드셰이크

| 비트 | 쓰는 쪽 | 뜻 |
|---|---|---|
| M2200 | PLC | 측정요청 (셀이 Z2에 정지) |
| M2201 | PLC | 수신완료 |
| M2250 | 브리지 | 값준비 |

순서:

1. 셀이 Z2에 서면 PLC가 M2200 ON
2. 브리지가 D2100~D2110 씀
3. 다 쓰고 나서 브리지가 M2250 ON
4. PLC가 D2100~ 블록을 자기 영역으로 복사, M2200 OFF, M2201 ON
5. 브리지가 M2250 OFF
6. PLC가 M2201 OFF

- M2250 ON 전에는 PLC가 D2100~을 읽지 않음.
- 3초 안에 M2250이 안 켜지면 PLC는 "측정 실패"로 처리. NG가 아니라 대기 (design-notes 판정 규칙).

## 내부저항 계산 (PLC)

IEC 61960-3 직류 내부저항(DCIR) 방식. 조항 번호는 원문 확인 전이라 문서에 아직 안 적음.

```
R [mΩ] = (V1 − V2) × 1000 / (I2 − I1)
예) (3670 − 3610) × 1000 / (3000 − 600) = 25
```

- 곱한 값이 16비트를 넘으니 32비트 명령(D*, D/) 사용.
- 결과는 D2304에 씀.

## 판정 기준값 (D2200~, 가정값)

멀티미터로 실제 셀 OCV 재고 나서 다시 정함.

| 디바이스 | 내용 | 초기값 |
|---|---|---|
| D2200 | OCV 하한 [mV] | 3500 |
| D2201 | OCV 상한 [mV] | 3800 |
| D2202 | 내부저항 상한 [mΩ] | 60 |
| D2203 | A 하한 = A/B 경계 [mV] | 3750 |
| D2204 | B 하한 = B/C 경계 [mV] | 3650 |
| D2205 | LOT NG 보류 기준 [건] | 3 |

- 전압 높은 쪽이 A. 초기값은 지금 PoC 래더(첫 스캔)에 들어간 값과 같음.

- 래더에 상수로 박지 않음. SCADA에서 바꾸면 분류가 바로 바뀌는 걸 시연용으로 씀.
- 값 생성기는 정상 셀 R을 20~45mΩ, 일부러 넣는 불량 셀은 70mΩ 이상으로 만듦.

## 판정 결과 (D2300~)

| 디바이스 | 내용 |
|---|---|
| D2300~D2301 | 판정한 셀 ID |
| D2302 | 결과 코드 (1 A, 2 B, 3 C, 5 대기, 9 NG) |
| D2303 | 사유 코드 |
| D2304 | 계산한 내부저항 [mΩ] |

| 비트 | 쓰는 쪽 | 뜻 |
|---|---|---|
| M2202 | PLC | 결과갱신 (브리지가 읽을 때까지 유지) |
| M2251 | 브리지 | 결과읽음 → PLC가 M2202 OFF |

사유 코드: 0 없음, 1 OCV 미달, 2 OCV 초과, 3 내부저항 초과, 4 QR 미판독, 5 측정 실패, 6 LOT 보류.

## 통신 상태

| 디바이스 | 쓰는 쪽 | 뜻 |
