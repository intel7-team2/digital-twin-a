# 설계 메모 (계획서에서 뺀 상세 규칙)

계획서 v0.17부터 교수님 피드백("계획서인지 보고서인지 모르겠다")에 맞춰 규칙·단서 위주의 상세 내용을 계획서에서 뺐다.
버린 게 아니라 구현할 때 참고하려고 여기 모아 둔다. 원문은 [archive/plan_v0.16.html](archive/plan_v0.16.html) 5~10쪽.

## 검사·판정

- A·B·C는 합격 셀의 **전압 구간** 이름이지 품질 등급이 아니다. 용량·수명 매칭까지 주장하지 않는다.
- 판정 순서: ① 측정 유효성(셀 ID·측정 시각·장비 상태) → ② 합격 여부(사양 상·하한) → ③ 구간 부여·세트 편차 확인.
- 측정 실패(접촉 실패·값 누락·기한 초과)는 불량으로 단정하지 않고 재측정 대기. LOT 미판독도 식별 확인 전까지 대기.
- 내부저항을 못 재면 미측정으로 표시하고 판정에서 뺀다. 그때 평가는 세트 안 전압 편차 비교로 한정.
- 시험 전에 고정할 것: 셀 모델·사양, 측정 온도·휴지 조건, 전압계 분해능, 구간 경계, 세트 허용 편차.

## 편차 비교 방법

- 세트 편차(mV) = 세트 안 최대 전압 − 최소 전압
- 감소율(%) = (순서별 평균 편차 − 구간별 평균 편차) ÷ 순서별 평균 편차 × 100
- 두 방식에 같은 합격 셀·입력 순서·관찰 시간을 쓴다. 편차와 함께 완성 세트 수·공급률·잔여 재고·대기시간을 같이 본다.
- 50%는 잠정 목표. 첫 측정(11/27) 뒤 적정성 다시 본다.

## 셀 상태와 LOT 보류

| 상태 | 조건 | 처리 |
|---|---|---|
| 합격 | 검사 유효·규격 적합 | LOT 정상이면 공급 가능 |
| 부적합 확정 | 유효 측정값이 규격 이탈 | 공급 금지, 격리, LOT의 NG 누계에 반영 |
| 재측정·식별 대기 | 접촉 실패·누락·기한 초과·LOT 미확인 | 판정 전까지 공급 금지, NG 누계에는 안 넣음 |
| LOT 보류 | 그 LOT 확정 NG 누계가 설정값(3건) 도달 | 신규 셀·대기 재고·미공급 세트 모두 공급 차단 |

- 보류 처리: ① 대상 재고 잠금 → ② 진행 중·인계된 셀은 수신 측에 ID 통보 → ③ 원인·검토자 기록 후 해제. 리셋으로 보류 이력을 지우지 않는다.
- NG 3건은 교육용 정책값이지 산업 기준이 아니다.

## 공급 인계와 장애 복구

- 공급 순서: 요청 기록(요청 ID·세트 ID·셀 ID 4개) → 물리적 인계(배출 수량·출구 감지·수신 확인 대조) → DB 반영(이벤트 ID로 중복 제거).
- 수신 확인 시간 초과: 자동 재배출 금지, 같은 요청 ID로 상태 조회만 재전송.
- 이미 처리한 요청 ID는 다시 배출하지 않는다.
- DB 저장 실패: 로컬 기록 후 같은 이벤트 ID로 재시도. 로컬 기록도 안 되면 새 공급 차단.
- 재시작·정전: 요청·완료 ID와 실제 수량을 대조하기 전에는 자동 운전 재개 금지.

## 실물·가상 동기화 범위

- 사전 데이터 시험: 실측 셀 ID·측정값을 가상 셀에 연결해 재현 시험. 실시간 연동이라고 부르지 않는다.
- 온라인 연계(목표): 셀 ID·측정 시각·상태와 준비·요청·수신 확인 교환. 갱신 주기·허용 지연은 통신 구성 확정 뒤 정한다.

## PLC 주소 충돌

- 11/18 1차 협의(디스코드)로 대역 확정: 로봇 프로젝트 0~1999, **2A 2000~2999**, 2B 3000~3999.
- 예전에 잡았던 `M3000~M4999`, `D3000~D4999`는 2B 대역이라 폐기.
- PoC 래더·태그맵·소프트 PLC는 11/18에 2000번대로 옮겼다 (M·D). 타이머 T는 대역 협의 전이라 아직 T0~T42 그대로.
- 실물 X/Y는 단자·모듈 구성과 기존 결선도를 확인한 뒤 할당한다.
- 디바이스별 배정과 Python 신호 규약은 [interface.md](interface.md)에 있다.
