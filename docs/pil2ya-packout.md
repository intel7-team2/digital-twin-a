# pil2ya · 2A 포장·출고 단독 검증본

첫 라인에서 셀이 픽업 위치까지 들어오면 클램프, Pick & Place, 팔레트 네 칸 적재, 원점 복귀, 롤러스톱 하강과 팔레트 배출을 확인한 검증본이다. 첫 라인 푸셔는 단독 시연을 위한 투입 보조다. 턴테이블 포트는 씬에 연결돼 있으며 회전·재배출 시퀀스는 이 CSV의 검증 범위 밖이다.

## 파일과 실행

1. Factory I/O에서 [검증 씬](../factoryio/scenes/pil2ya_packout.factoryio)을 연다.
2. GX Works2의 Q03UDV 프로젝트에서 [래더 CSV](../plc/pil2ya_packout.csv)를 가져와 컴파일한다. [글로벌 코멘트](../plc/pil2ya_packout_comments.csv)는 Global Device Comment로 가져온다.
3. GX Simulator2를 시작하고 MX Component에서 해당 시뮬레이터를 가리키는 논리국을 설정한다.
4. 저장소 루트에서 아래 명령을 실행한다. 논리국이 1번이 아니면 값을 바꾼다.
5. Factory I/O Modbus TCP/IP Client를 127.0.0.1:502에 연결하고 Run을 누른다.

```powershell
python -u .\plc\pil2ya_packout_bridge.py --station 1 --trace
```

팀 시연용 START_LINE.cmd와 이 브리지는 같은 로컬 포트를 사용하므로 동시에 실행하지 않는다. 이 씬과 래더는 Factory I/O 및 GX Works2에서 내보낸 독립 검증 스냅샷이다. 팀 통합 주소는 [태그맵](../plc/tagmap.md)을 기준으로 합의하고, 통합 시 ② 푸셔·본선 벨트 제어를 분리한다.

## 검증본의 주요 주소

| 신호 | 주소 |
|---|---|
| 셀 감지 / 팔레트 감지 (감지 시 LOW) | M2710 / M2711 |
| 클램프 완료 / 명령 | M2720 / M2767 |
| 로봇 흡착 | M2760 |
| 실제 XYZ / 목표 XYZ | D2060~D2062 / D2063~D2065 |
| 위치 수신 완료 / 목표 전송 허용 | M2721 / M2781 |
| 팔레트 롤러 / 스톱 올림 | M2752·M2753 / M2768 |
| 턴테이블 0°·90° / Front·Back | M2715·M2716 / M2717·M2718 |
| 턴테이블 회전 / 진입·배출 롤러 | M2761 / M2762·M2763 |
| 팔레트 적재 카운트 | C400 |

집기 XYZ는 80 / 150 / 880이다. C400의 현재값 0~3에 대응하는 배치 XY는 (820, 250), (630, 250), (820, 565), (630, 565)이며 배치 Z는 880이다. 네 번째 셀 이후 스톱을 내리고 T7로 배출 시간을 잡은 뒤 카운터를 초기화한다. 내보낸 CSV에는 흡착 해제 후 T6 K3을 적용한 수정이 포함돼 있으며, 해당 수정 후 현장 동작은 별도로 확인한다.

## 팀원 인계

- AI에 작업을 넘길 때 이 문서와 함께 씬, 래더 CSV, 브리지 두 파일을 읽도록 한다. 래더 CSV와 글로벌 코멘트는 GX Works2 내보내기/가져오기 형식에 맞춘 UTF-16LE 탭 구분 파일이다. 전체 포트 순서는 브리지의 INPUTS / OUTPUTS / NUMERIC_DEVICES / TARGET_DEVICES와 씬의 ModbusTCPClient 블록으로 대조할 수 있다.
- ②에서 셀을 인계받는 경계는 M2710 셀 도착과 M2750 픽업 이송이다. 단독 시험용 색상 판정, M2551 본선 벨트, M2552 푸셔와 T1은 통합 시 ②의 구현과 중복되지 않게 분리한다.
- ③의 후속 경계는 C400 완료와 팔레트 배출이다. 턴테이블 작업은 M2715~M2718의 위치·팔레트 센서와 M2761~M2763의 회전·롤러 명령부터 이어간다. 센서 극성과 진입·배출 방향은 씬에서 확인한 뒤 래더에 적용한다.
- 팀 씬과 래더에 합칠 때는 팀 태그맵과 실제 장치 소유권을 먼저 대조하고, 합의된 주소로 팀 생성 스크립트를 갱신한다. 이 검증본은 독립 실행과 비교에 사용한다.
