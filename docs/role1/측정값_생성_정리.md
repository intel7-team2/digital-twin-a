# 역할① 측정값(전압·저항) 만들기 정리 (2026-11-27)

측정기(머시닝 센터)는 블랙박스 공정이다. 셀이 측정기에 들어가는 순간 PLC가 값을 만들어 기록한다.
(실무라면 측정기에서 통신으로 받는 자리)

## 1. 값 범위
| | PLC 저장값 | 화면 표시 | 정상 | NG |
|---|---|---|---|---|
| 전압 V | 349~381 (정수) | 소수점 2자리 → 3.49~3.81 V | 350~380 | 349, 381 |
| 저항 R | 15~61 (정수) | 그대로 mΩ | 15~60 | 61 |
| 재측정 | R = 0 | | 약 2% | |

- 정상 범위는 18650 셀 실제 값 근처로 잡음 (출하 전압 3.6~3.7 V, 내부저항 수십 mΩ)
- NG가 가끔 나오게 범위 끝에 하나씩 추가 (저항은 높을 때만 문제라 위쪽만)

## 2. 33과 47이 나오는 공식
- 스톱워치 크기 = 최대값 − 최소값 + 1
- 더하는 수 = 최소값

| | 최소 | 최대 | 스톱워치 크기 | 더하는 수 |
|---|---|---|---|---|
| 전압 | 349 | 381 | 381 − 349 + 1 = **33** | **349** |
| 저항 | 15 | 61 | 61 − 15 + 1 = **47** | **15** |

범위를 바꿀 때는 최소·최대만 정하고 이 공식으로 다시 계산한다.

## 3. 원리 (스톱워치 찍기)
- D2310, D2311은 스캔마다 1씩 올라가다 끝에 오면 0으로 돌아가는 "스톱워치"
- 셀이 측정기에 들어가는 순간(Is Busy ↑) 그때의 숫자를 찍어서 최소값을 더함
- 셀이 들어오는 시간이 매번 달라서 값이 매번 다르게 나옴 (RND 대신 배운 명령만 사용)
- ↑(상승 펄스)여야 한 번만 찍혀서 값이 고정됨

## 4. 래더
```
 SM400 ─────────────────── INC D2310           전압 스톱워치 (0~32)
 [>= D2310 K33] ────────── MOV K0 D2310

 SM400 ─────────────────── INC D2311           저항 스톱워치 (0~46)
 [>= D2311 K47] ────────── MOV K0 D2311

 X1042(↑) ──┬──────────────────── + D2310 K349 D2402    전압
            ├──────────────────── + D2311 K15  D2403    저항
            └── M2407 ─────────── MOV K0 D2403          재측정 대상이면 저항 0
```
- `+ A B C` = C에 A+B를 넣음 (숫자 3개). `+ A B`는 B에 계속 더해져서 안 됨
- `[>= A B]` = A가 B 이상이면 (앞이 기준)
- 저항 넣는 줄이 먼저, 0으로 덮어쓰는 줄이 나중

측정기 2~4: X1052 / X1062 / X1072, 결과 칸 D2412~ / D2422~ / D2432~ (스톱워치는 같이 씀)

※ 11/27 변경: 재측정 여부는 팔 돌 때(M2400↑) 정함 → M2400↑ ─ [< D2311 K1] ─ SET M2407 (약 2%)
   값 계산은 측정 시작(X1042↑), 측정 끝(X1042↓)에 RST M2407. Lids = M2407 → (Y1046)

## 5. 등급 (팀 확정: 전압 × 저항)
판정 순서
1. V 또는 R = 0 → 재측정 (코드 5, Lids ON)
2. V < 350, V > 380, R > 60 → NG (코드 9)
3. V×R < 11000 → A(1), 11000 이상 16500 미만 → B(2), 16500 이상 → C(3) (범위로 나눠서 순서 상관없음)

V가 365 정도면 A ≈ R 15~30, B ≈ 31~45, C ≈ 46~60 (거의 3등분)

## 6. 저장 위치 (측정기 n = D2400 + 10×(n-1))
| +0 | +1 | +2 | +3 | +4 | +5 |
|---|---|---|---|---|---|
| 셀 ID | LOT | 전압 | 저항 | V×R | 결과 코드 |

## 7. 남은 것
- V×R → D2404 (곱셈 결과 32비트라 임시 D2312·D2313 사용 후 MOV)
- 등급 판정 → D2405, 재측정이면 Lids ON
- 측정기 2~4 복사
- SCADA에 전달: 전압은 소수점 2자리 표시, 등급 코드 1/2/3/5/9 → A/B/C/재측정/NG
