 4. 측정기 (머시닝 센터) 4대  — 4대 모두 같은 순서
--------------------------------------------------------------
     측정기 1 = X/Y 1040번대
     측정기 2 = X/Y 1050번대
     측정기 3 = X/Y 1060번대
     측정기 4 = X/Y 1070번대

 오프셋 | 입력 X              | 출력 Y
 -------+---------------------+---------------------------------
  +0    | STn_IN    입구 셀   | STn_IN_BELT    입구 벨트
  +1    | STn_OUT   출구 셀   | STn_OUT_BELT   출구 벨트
  +2    | STn_BUSY  측정 중   | STn_START      Start (0.5초 펄스)
  +3    | STn_ERROR 이상      | STn_STOP       Stop
  +4    | (예비)              | STn_RESET      Reset
  +5    | (예비)              | STn_EXIT_STOP  출구 블레이드 (ON = 막음)
  +6    | (예비)              | STn_LIDS       Produce Lids (ON = 뚜껑 = 재측정)

 예) 측정기 2 Busy = X1052,  측정기 3 Start = Y1062,  측정기 4 Lids = Y1076
 Opened, Progress 태그는 연결하지 않음.

 [풀어 쓴 표]  ※ Factory I/O 번호는 0부터: Machining Center 0 = 측정기 1

 입력 X                       측정기1   측정기2   측정기3   측정기4
 Is Busy   (가공 중 ON)        X1042     X1052     X1062     X1072
 Has Error (이상 ON)           X1043     X1053     X1063     X1073
 출구 센서 (지금 안 씀)        X1041     X1051     X1061     X1071

 출력 Y                       측정기1   측정기2   측정기3   측정기4

 Stop                          Y1043     Y1053     Y1063     Y1073
 Reset (Has Error 풀기)        Y1044     Y1054     Y1064     Y1074
 Produce Lids (ON = 재측정)    Y1046     Y1056     Y1066     Y1076
 출구 벨트                     Y1019     Y101A     Y101B     Y101C

 내부                         측정기1   측정기2   측정기3   측정기4
 사용 중                       M2400     M2410     M2420     M2430
 측정 완료 (판정용)            M2402     M2412     M2422     M2432
 셀 기록 시작 D                D2400     D2410     D2420     D2430

 동작 정리 (11/26)
  - Start 버튼(X10E0) → SET M2440 / RST M2441 → M2440이 Start 4개 ON
  - Stop·비상정지   → SET M2441 / RST M2440 → M2441이 Stop 4개 ON
    (서로 RST하는 인터록, 타이머 없음)
  - 분기에서 팔 돌릴 때 → SET M24n0 (사용 중)
  - Is Busy 하강(↓)    → RST M24n0 (비었음)
  - 머시닝 센터는 Start 후 셀이 들어오면 로봇이 알아서 집어 가공

 5. 내부 비트 M
--------------------------------------------------------------
 M2000          운전 중 (Start SET, Stop·비상정지 RST)
 M2001~M2099    공통 (알람, 리셋 등)

 분기 팔 단계 (분기 n 기준 = M2101 + 10×(n-1))  ← 11/27 '감지' 없앰
  분기 1  M2101 팔돌림 / M2102 센서통과(예비)   (팔 유지 T201)
  분기 2  M2111 팔돌림 / M2112 센서통과(예비)   (팔 유지 T202)
  분기 3  M2121 팔돌림 / M2122 센서통과(예비)   (팔 유지 T203)
  분기 4  M2131 팔돌림 / M2132 센서통과(예비)   (팔 유지 T204)
  팔 접기: 방법 A(팔 돌리자마자 타이머) RST M2101
           방법 B(센서 OFF 후 타이머)   BKRST M2101 K2
  Reset: BKRST M2101 K33 (분기 단계 전부), BKRST M2400 K40 (측정기 비트 전부)

 측정기 사용 중 (팔 돌릴 때 SET ~ Is Busy 하강 때 RST)
  M2400  측정기 1 사용 중
  M2410  측정기 2 사용 중
  M2420  측정기 3 사용 중
  M2430  측정기 4 사용 중
  → 분기 조건에 b접점으로 넣어서, 사용 중이면 팔 안 돌리고 지나보냄
  → Emitter: 4대 중 하나라도 비어 있을 때만 ON (/M2400~/M2430 병렬)

 측정기별 (측정기 n 기준 = M2400 + 10×(n-1))
  측정기 1 M2400~  측정기 2 M2410~  측정기 3 M2420~  측정기 4 M2430~
  +0  사용 중 (예약 ~ 배출 끝)
  +1  측정 중
  +2  측정 완료, 합류 대기
  +3  배출 중
  +5  고장으로 분배 제외
  +7  재측정 대상 (M2407/17/27/37, 팔 돌 때 SET, Is Busy↓ RST)

 측정기 공통 제어
  M2440  측정기 4대 Start (Start 버튼 SET, Stop·비상정지 RST)
  M2441  측정기 4대 Stop  (Stop·비상정지 SET, Start 버튼 RST)

 ②와 주고받는 신호 (구역 사이)
  M2900~M2903   측정기 1~4 출구 도착   ① → ②
  M2910~M2913   측정기 1~4 합류 허가   ② → ①  (②가 없을 때는 강제 ON으로 시험)

 7. 판정 설정값  (D2200~, 래더에 숫자 직접 쓰지 말 것)
--------------------------------------------------------------
 D2200   350     V 하한 (3.50 V)
 D2201   380     V 상한 (3.80 V)
 D2202   60      R 상한 (mΩ)
 D2203   11000   A / B 경계 (지표 11000 미만 = A)
 D2204   16500   B / C 경계 (16500 미만 = B, 이상 = C)
 D2205   3       LOT NG 한도
 D2206   (미사용) 측정 실패는 D2311 < 1로 처리 (약 2%)
 D2207   5       외관 NG 비율 (%)   ← 팀 확인 필요

 값 만들기 (11/27, RND 대신 카운터 찍기):
            SM400 → INC D2310, D2310 >= 33 이면 MOV K0  (D2311은 47)
            측정기 Is Busy ↑ 순간에
            V = D2310 + 349   (349~381)
            R = D2311 + 15    (15~61)
            팔 돌 때(M2400↑) D2311 < 1 이면 SET M2407 (재측정 대상, 약 2%)
            M2407 이면 R = 0,  Lids = M2407 → (Y1046),  X1042↓ 때 RST M2407
 판정 순서:  1) V 또는 R = 0           → 재측정 (Lids ON)
            2) V < D2200, V > D2201, R > D2202 → NG
            3) V×R < D2203 → A,  < D2204 → B,  나머지 → C
