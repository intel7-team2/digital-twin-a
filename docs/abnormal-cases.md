# 비정상 상황 시험 (8건, 초안)

계획서 확인 기준 "비정상 상황 8건 기대 동작 일치"용. 씬이 나오기 전에 **무엇을 어떻게 일으키고, 뭐가 나와야 통과인지**를 먼저 적어 둔다.
씬·래더가 바뀌면 "재현"과 "확인 신호" 칸만 고치면 된다. 규칙 근거는 [설계 메모](design-notes.md).

"line_v0 지금"은 현재 시연 씬([run-line.md](run-line.md)) + `plc/line_v0.txt` 기준으로 읽은 것이다. 실제로 돌려 본 결과가 아니다.

## 공통

- 시험마다 영상 + 태그 기록(`plc/observe.py`, 상태 JSON `http://127.0.0.1:8765/`) + DB 이벤트를 같이 남긴다.
- 통과 = 기대 동작·알람·복구가 모두 맞고, **셀이 사라지거나 NG·보류 셀이 공급으로 나가지 않음**.
- 새 시험은 상단 ▶로 편집 모드에 갔다가 다시 ▶ (조작반 Reset은 셀을 안 지움).

## 시험표

| # | 상황 | 재현 | 기대 동작 | 알람 | 복구 | line_v0 지금 |
|---|---|---|---|---|---|---|
| 1 | 센서 OFF 고착 | 운전 중 Factory I/O에서 분류 구간 센서(예: At pusher A)를 Force OFF | 셀이 다음 센서에 제때 안 오면 감시 타이머로 이상 정지. 셀을 다른 레인으로 밀지 않음 | 위치 미도착 (설비·센서 이름) | 센서 Force 해제 → 셀 위치 확인 → Reset → Start | **있음**: 분류 구간 20초 초과 시 M2390 (T40) |
| 2 | 센서 ON 고착 | 셀 없는 상태에서 도착 센서(Cell arrived)를 Force ON | 셀이 없는데 들어온 것으로 세지 않음. 일정 시간 ON 지속이면 이상 | 센서 이상 (계속 ON) | Force 해제 → Reset | **없음**: ON 지속 감시 없음. 셀 수가 늘어날 수 있음 |
| 3 | 잼 (셀 걸림) | 검사 블레이드 해제 후 셀을 손으로 잡아 두거나 벨트 끔 Force | 다음 셀 투입 중지, 이상 정지. 뒤 셀이 앞 셀을 밀어내지 않음 | 잼 (구간) | 셀 제거 또는 위치 확인 → 재고 대사 → Reset | **일부**: 블레이드 해제 후 8초 미출발은 진행 상태만 지우고 카운트 (T30, D2460). 이상 정지는 아님 |
| 4 | 비상정지 | 조작반 E-stop | 모든 출력 즉시 OFF, 운전 해제. 해제만으로 재시작 안 함 | 비상정지 | E-stop 해제 → Reset → Start. 진행 중 셀 위치·재고 대사 뒤 재개 | **있음**: M2018 B접점으로 M2300 해제. 재개 전 대사는 없음 |
| 5 | 레인 만재 | 2B 수신을 막아 A 레인에 4개 쌓인 뒤 A 셀 1개 더 투입 | 5번째 A 셀은 분기점 앞에서 대기하거나 우회 없이 정지. 분기점을 막지 않음. B·C는 계속 | 레인 A 만재 | 2B 수신 → 레인 비면 자동 재개 | **일부**: 레인 재고 D2450~ 있음. 만재 시 대기 동작은 확인 필요 |
| 6 | LOT NG 3건 | 같은 LOT에 규격 밖 전압 3개 넣기 (임시 표 D2600~ 또는 시뮬 값) | 그 LOT 보류. 새로 들어오는 셀 NG 레인, **레인에 이미 있는 같은 LOT 셀과 미공급 세트도 공급 차단** | LOT 보류 (LOT 번호) | 원인·검토자 기록 뒤 보류 해제. **Reset으로 보류가 지워지면 안 됨** | **일부**: 신규 셀 NG 처리는 있음(M2500~). 레인 재고 차단은 확인 필요. Reset이 보류를 지움(설계와 충돌) |
| 7 | 2B 미준비 | 2B 준비 신호 OFF 상태로 세트 완성 | 세트 0개 배출. 준비 ON 되면 한 레인만 배출. 수신 확인 없으면 재배출 안 함 | 2B 미준비 (오래가면) / 수신 시간 초과 | 2B 준비 → 자동 배출. 시간 초과는 같은 요청 ID로 상태 조회만 | **없음**: 준비·수신 확인 신호가 래더에 없음. 배출 40초 초과 시 이상 정지(T31)만 있음 |
| 8 | 통신 단절 | 운전 중 소프트 PLC 종료 또는 Factory I/O 드라이버 Disconnect | 1초 넘게 끊기면 출력 OFF, 진행 상태 초기화. 복구 후 자동 재개 안 함 | 통신 단절 | 연결 복구 → 셀·재고 대사 → 씬 새로 시작 | **있음**: softplc가 1초 단절 시 출력 지움. 대사 절차는 없음 |

## 지금 비어 있는 것 (PLC·Factory I/O 쪽에 넘길 것)

- 2번 센서 ON 고착 감시, 7번 2B 준비·수신 확인 신호. 래더에 아예 없음.
- 3번 잼: 지금은 카운트만 하고 계속 돎. 이상 정지로 바꿀지 정해야 함.
- 6번: Reset이 `M2500~`(LOT 보류)와 `D2500~`(NG 횟수)를 지움. 설계 메모는 "리셋으로 보류 이력을 지우지 않는다". 이상 리셋과 보류 해제를 나눠야 함 ([HMI 태그 매핑](hmi/plc-tag-map.md) RESET 충돌과 같은 이야기).
- 4·8번: 재개 전 "요청·완료 ID와 실제 수량 대조"는 사람이 하는 절차로 둘지, HMI에서 확인 버튼으로 둘지.
- v2 씬(검사기 4대 + 재검)으로 가면 1·3번 감시 구간이 늘어남. 재검 무한 순환([2a-data-design](2a-data-design.md) 배치 검토 1번)도 시험 항목으로 추가 검토.
