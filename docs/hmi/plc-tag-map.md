# PLC 태그 매핑표와 현장 확인 항목

이 표는 화면 데이터 모델과 분리된 **어댑터 입력 명세**다. 주소는 [PLC 인터페이스](../interface.md), [생성된 PoC 태그맵](../../plc/tagmap.md), [PoC 래더](../../plc/line_v0.txt)에서 가져왔다. 주소에 쓰기 동작을 할당하는 승인표가 아니다. HMI가 사용하는 필드와 명령은 [논리 계약](interfaces.md)을 따른다.

## `line_v0` PoC에서 확인한 주소

로컬 소프트 PLC JSON의 `connected`, `simulation_running`, `sensors`, `outputs`, `vision`, `memory`, `events`는 코드에서 확인했다. 어댑터는 현재 화면에 필요한 필드만 선별한다. `simulation_running`은 씬 실행이고, `memory.M2300`은 운전 자기유지 신호다. 주소가 JSON에 있어도 관측하지 않은 값은 해당 기능의 사용 가능 근거가 되지 않는다.

| 논리 표시 | `line_v0` 근거 | 소유·단위 또는 주의 |
| --- | --- | --- |
| `scene_link`, `scene_running`, `scene_pause`, `scene_reset_observed` | 소프트 PLC `connected`/`simulation_running`, Modbus Coil `19/20/21` | Coil은 씬 입력. PLC용 HMI START/STOP/RESET 주소로 재사용하지 않는다. |
| `run_latched`, `line_fault` | `M2300`, `M2390` | 래더 내부 비트. `M2390`은 종합 이상이므로 구체 알람 코드가 없는 경우 하나의 PoC 이상으로만 표시. |
| `start_panel`, `stop_panel`, `estop_panel`, `reset_panel` | `M2015`, `M2016`, `M2018`, `M2017` | 현재 씬 조작반 입력. Stop·E-stop은 PoC B접점으로 평상시 `ON`. E-stop 관측은 실물 안전 상태 검증과 별도. |
| `start_light`, `stop_light`, `reset_light` | `M2117`, `M2118`, `M2119` | PoC 래더 출력. 램프만으로 명령 완료나 안전 상태를 판단하지 않는다. |
| `entry_detected`, `inspection_position`, `exit_detected` | `M2000`, `M2001`, `M2014` | 씬 센서 비트. `M2014`는 출구 감지이며 상대 라인의 수신 확인과 별도. PoC의 검사 위치 하나를 v2 네 레인에 복제하지 않는다. |
| `lot_raw`, `cell_serial_poc`, `inspection_values_poc` | `D2000` LOT, `D2400` PoC 순번, `D2420` OCV, `D2421` IR | LOT 원값, 셀 순번, mV/mΩ. 측정값은 PoC 내부 표에서 생성. 전역 Cell ID와 연결은 따로 확인한다. |
| `route_poc` | `D2422` 검사 목적지, `D2423` 분류 구간 전달 | PoC 목적지 `0=NG, 1/2/3=A/B/C`. 유효한 셀·단계 문맥에서만 해석. v2 `D2302` 상태 코드와 혼용 금지. |
| `lot_hold_poc`, `lot_ng_count_poc` | `M2500~M2509`, `D2500~D2509` | PoC는 LOT 코드로 인덱싱. 최종 전기 NG 집계나 공용 LOT 상태로 보장할 수 없다. |
| `lane_counts_poc`, `supply_counter_poc` | `D2451~D2453`, `D2460` | PoC 집계. 레인 실제 점유·Kit 4개 슬롯 검증·수신 확인과 별개. |
| `criteria_initial_poc` | `D2200~D2205` | PoC 첫 스캔에서 초기값 설정. 실제 셀 사양이나 승인된 PLC 설정은 별도로 확인한다. |

**RESET 충돌.** 현재 `M2017` 래더 분기는 진행 상태·이상과 함께 `D2440~D2443`, `D2450~D2453`, `D2500~D2509`를 초기화하고 `M2500~M2509`를 해제한다. 씬에 남은 물리 셀도 제거하지 않는다. v0.2의 `RESET_FAULT`는 LOT 보류 및 인계 대사를 유지해야 하므로 이 분기에 연결하지 않는다. 별도 합의된 적합한 리셋 동작과 시험이 필요하다. PoC 씬에서 새 시연을 시작하는 절차는 [실행 안내](../run-line.md)를 따른다.

## v2 규약에서 검토할 주소

아래는 문서의 초안 또는 검토 범위다. `line_v0`에서 동작한다거나 실 PLC가 이 주소를 사용한다고 간주하지 않는다.

| 초안 주소 | 논리 필드와 예상 소유 | 의존 조건 |
| --- | --- | --- |
| `D2100~D2101` | 셀 번호, 브리지 작성; 문서의 32비트 하위 워드 우선 | 실제 Cell ID·회차 결합과 레인별 동일 값의 시도 대응 관계 확인 |
| `D2102~D2110` | LOT, OCV, V1/I1, V2/I2, 방향, 읽기 상태, 전송 번호. 브리지 작성 | mV/mA 정수 원값. 폭·부호·유효값·완전 게시 기준과 네 레인별 전송 경로 승인 |
| `M2200`, `M2201`, `M2250` | 측정 요청·수신 완료는 PLC, 준비는 브리지 | 측정 전용 핸드셰이크. 문서의 3초는 측정 준비 제한 후보이며 HMI 명령 타임아웃으로 사용하지 않는다. |
| `D2200~D2205` | OCV 하·상한, IR 상한, A/B·B/C 경계, LOT NG 한도 | mV·mΩ·건. 설정 적용 시점과 다중 워드 일괄 승인/읽기 확인 규칙 필요. 재검 한도 주소 미정. |
| `D2300~D2304`, `M2202`, `M2251` | 결과 셀 번호, 코드, 사유, IR. 결과 갱신은 PLC, 읽음은 브리지 | D2302의 `1/2/3=A/B/C`, `5=대기`, `9=NG`는 v2 초안 해석. 외관 코드, 검증 확정 조건과 분리. |
| `M2203`, `M2252` | 각각 PLC·브리지 하트비트 | 초안은 1초 토글과 브리지 신호 3초 미변화 판단. PoC `connected`의 1초 링크 기준과 별도. HMI의 발행 주기·유효 시간은 시험 뒤 승인. |
| `D2700~D2799` | 이벤트 메일박스 후보 | 기존 `D2400~D2799` 셀 추적 범위와 충돌 가능. 범위·레코드 배치·순번·넘침·ACK 전부 미정. |
| `D2800~D2899` | 상대 라인 준비·요청·인계 후보 범위 | 팩/2B 경계, 키, 수량·확인 신호와 책임자 협의 전 개별 주소를 부여하지 않는다. |

## 새 매핑에 필요한 기록

PLC 담당자와 확정할 때 각 항목에 `논리 필드 또는 명령`, `씬·래더 버전`, `프로토콜/영역/주소`, `비트 또는 워드 폭·부호·워드 순서`, `원 단위·스케일`, `유효 조건과 리셋 의미`, `권위 원천/읽기·쓰기 주체`, `관측·응답 테스트 근거`를 적는다. HMI의 `START`, `STOP`, `RESET_FAULT` 요청·상관키·응답 주소, 설정 일괄 적용 ACK, 알람 확인, LOT 보류 해제, 상대 라인 인계는 모두 **TBD**다. T/C/X/Y 대역과 실물 I/O 결선도도 별도 확인한다. 확인 전에는 빈 주소를 개발 가정으로 채우지 않는다.
