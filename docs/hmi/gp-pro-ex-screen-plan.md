# Cellect 2A GP-Pro EX 작화 설계

기존 [HMI v0.2 화면 설계](screens.md)를 운전자 업무별로 나눈다. 메인에서 라인 상태와 이상 위치를 찾고, 설비 상세에서 원인과 다음 조치를 확인한다. 생산 추이, 편차 감소율, 장기 추적은 [SCADA 업무별 화면](../scada/README.md)에서 조회한다.

## 메인 메뉴와 화면 번호

| Base Screen | 화면 | 우선 표시 | 터치해서 이동 |
| --- | --- | --- | --- |
| **B100** | **메인 운전** | 라인 상태·회차·PLC 연결, 공정 평면도, 현재 예외 사유, 투입·재검 대기·완료 Kit·열린 알람 | 검사기 → B210, 포장 구역 → B400, 알람 → B500 |
| **B200** | **설비 관제** | T1~T4·RT를 먼저 표시하고 Vision·이송·분류·포장 상태를 묶어 표시 | 검사기·RT → B210, 보조 설비 → B220 |
| **B300** | **검사·분류** | Cell ID, 외관 판정, OCV(V)·IR(mΩ), 최초·재검·최종 판정, 특성군과 진입 확인 | 검사기 → B210, 연결된 Kit → B400 |
| **B400** | **포장·인계** | A/B/C 레인 대기량, Kit ID, 구성 셀 4슬롯, 포장 상태와 팩 인계 | 슬롯 Cell ID → B300, 인계 이상 → B500 |
| **B500** | **알람** | 활성 알람, 설비·발생 시각, 미확인 여부, 조치 안내, LOT 보류 대상·사유 | 해당 설비 → B210/B220, 기준 조회 → B510 |

### 설비 및 설정 상세

| Base Screen | 화면 | 표시 내용 |
| --- | --- | --- |
| **B210** | 검사기 상세 | 선택한 T1~T4·RT, 관측 상태·시각, 현재 Cell ID, 검사 시도, 최근 측정값·판정, 활성 알람. RT에서 최초 판정·재검 사유·최종 판정을 나란히 확인한다. |
| **B220** | 보조 설비 상세 | IN·VIS1·VIS2·IDC는 감지와 ID 결과, SORT·LA~LC는 목표 분류와 확인된 레인, BOX·OUT은 슬롯과 인계 단계, RJ1·RJ2는 실제 배출 확인을 보여준다. |
| **B510** | 판정 기준 조회 | 적용 중인 OCV 하·상한, IR 상한, A/B·B/C 경계, LOT 보류 기준, 재검 한도와 버전. 초도 화면은 읽기 전용이다. |

B210과 B220은 설비를 선택해 내용을 바꾸는 공통 상세로 작화한다. 초도 작업에서 화면 간 선택 전달이 어려우면 상세 화면 내부에 로컬 선택 탭을 둔다. 공통 메뉴와 화면 전환은 Base Screen에 연결하며, 상세에서 `설비 목록`이나 `메인`으로 돌아갈 수 있게 한다.

## 배치 예시

```text
B100 메인 운전
┌ Cellect 2A  [설계 미리보기]  [회차 —]  [PLC 미연동]  [마지막 관측 —] ┐
│ 라인 상태 —       운전 허용 —       비상정지 관측 —                  │
│ IN → VIS1 → VIS2 → T1~T4 → IDC → SORT → A/B/C → BOX → OUT          │
│            ↘ 외관 NG               ↘ RT → 합류 또는 최종 NG         │
│ 투입 —       재검 대기 —       완료 Kit —       열린 알람 —          │
│ 현재 예외 —                        START    STOP    RESET          │
│ 메인       설비        검사·분류        포장·인계        알람        │
└────────────────────────────────────────────────────────────────────┘

B210 검사기 상세
┌ 검사기 T2       상태 —      최근 관측 —      [설비 목록]              ┐
│ T1         T2         T3         T4         RT                     │
│ 현재 Cell ID —        시도 —        진행률 —                        │
│ 최근 검사  OCV — V    IR — mΩ       판정 —                          │
│ 활성 알람 —                     작업자 확인 안내 —                   │
│ 메인       설비        검사·분류        포장·인계        알람        │
└────────────────────────────────────────────────────────────────────┘
```

- **상단 고정**은 데이터 환경·회차·브리지/PLC 연결·마지막 관측, **하단 고정**은 5개 메뉴와 현재 메뉴 표시를 둔다. 공정 카드는 화면 이동에 사용한다.
- B200은 검사기와 활성 이상을 먼저, B300은 최신 판정과 측정값을 먼저, B400은 4슬롯과 인계 단계를 먼저, B500은 미확인 활성 알람을 먼저 배치한다.
- 화면 이동 시 선택한 설비·Cell·Kit 문맥을 유지한다. 표시기 모델과 해상도가 확정되면 글꼴·터치 영역·줄바꿈을 맞춘다. 긴 ID와 알람 문구의 잘림은 오프라인 시뮬레이션에서 확인한다.

| 화면 | 위에서 아래로 그릴 본문 |
| --- | --- |
| B200 설비 관제 | 검사기 5개 카드 → Vision·이송·분류·포장 설비 목록 → 선택 설비의 최근 알람 |
| B300 검사·분류 | 선택 Cell ID·LOT → 외관 및 전기검사 결과 → 최초·재검 비교 → 목표 특성군과 실제 레인 |
| B400 포장·인계 | 특성군별 레인 → 선택 Kit ID와 1~4 슬롯 → 포장·요청·출구·수신 확인 |
| B500 알람 | 열린 알람과 LOT 보류 요약 → 활성 목록 → 선택 알람의 시각·원인·조치 안내 |

## 표시와 조작 규칙

| 주제 | 적용 규칙 |
| --- | --- |
| **설비 상태** | 청록 운전 중, 초록 정상 대기, 주황 공급·후단 대기, 빨강 설비 이상, 회색 정지·미수집. 상태 문구와 출처를 함께 표시한다. |
| **데이터 품질** | 미연동·미수집·관측 지연·통신 단절을 구분한다. 마지막 관측을 표시할 때는 시각을 붙인다. 확인된 0건은 `0`, 집계 근거가 없으면 `미수집`이다. |
| **검사·특성군** | OCV 원값 mV는 화면에서 V로 환산하고 IR은 mΩ를 유지한다. 결측은 `미측정`으로 표시한다. A/B/C는 전기적 특성군이며 같은 계열색을 사용한다. |
| **포장·인계** | 포장, 요청, 출구 통과, 수신 확인을 별도로 표시한다. 동일 특성군의 서로 다른 셀 4개와 고유 슬롯이 확인되면 `구성 확인`을 표시한다. |
| **조작** | 초도 작화에서 START·STOP·RESET은 비활성. 비상정지는 상태 관측으로만 표시한다. 인터록·요청·응답은 승인된 브리지 계약으로 연결한다. 알람 확인·LOT 보류 해제는 각각 별도 절차다. |

첨부 씬에서 같은 열의 Machining Center 4대, 오른쪽 별도 1대, Pick & Place와 턴테이블 각 3대를 확인했다. `Machining Center 0/1/2/4/5`에는 `Is Busy`, `Has Error`, `Opened`, `Progress`가 있다. 씬 객체와 T1~T4·RT의 대응, PLC 주소, `Progress`가 전기검사 진행률을 의미하는지는 담당 조 확인이 필요하다. 확정 전에는 해당 값을 `미연동`으로 표시한다. ## GP-Pro EX 작화 순서와 검수

1. **공통 틀 → B100.** 표시기 모델을 선택하고 상·하단과 공정도를 작화한다. 화면 전환 스위치로 메인 메뉴 5개를 먼저 연결한다.
2. **B200 → B210/B220.** 설비 목록과 상세를 만든다. T3 이상 예시로 메인에서 관련 상세와 알람까지 두 번 이내의 터치로 확인한다.
3. **B300 → B400 → B500/B510.** 최초·재검 판정, 4슬롯, 인계 단계, 알람과 읽기 전용 설정을 구현한다.
4. **오프라인 시뮬레이션.** 정상 대기, 미수집, 통신 단절, T3 이상, RT 재검 통과, 슬롯 3개 적재, 출구 후 수신 미확인, LOT 보류를 각각 확인한다. 조작 버튼은 비활성 상태를 유지한다.
5. **연동 인수.** 표시기 모델·GP-Pro EX 버전, 브리지 통신 방식, 씬과 스테이션의 대응, 읽기 주소를 대조한다. 실제 요청·설정 쓰기는 브리지 담당과 인수 조건을 합의한 뒤 검증한다.

이 문서는 작화 명세다. GP-Pro EX 프로젝트 파일 생성과 실제 PLC·씬 연결은 별도 단계다. [기존 확장·검증 계획](rollout.md)
