# DB 담당 조원에게 전달할 Cellect 2A 연동 협의사항

안녕하세요. Cellect 2A Grafana에서 팀 공용 DB의 생산량, 검사값, Buffer 수량, 완료 Kit와 셀·Kit 이력을 읽기 전용으로 조회하려고 합니다. 아래 항목을 기준으로 현재 제공 가능한 조회 데이터와 결정이 필요한 항목을 확인 부탁드립니다. 기존 테이블이나 뷰를 제공해 주시면 SCADA 쪽에서 [논리 조회 명세](read-interface.md)에 매핑하겠습니다.

## 먼저 받을 자료

| 요청 | 확인할 내용 |
| --- | --- |
| 스테이징 조회 대상 | DB 버전과 조회 정의의 브랜치·커밋 또는 문서 버전, 조회 가능한 테이블·뷰와 필드 목록, 읽기 전용 역할의 접근 대상 |
| 접속 정보 | 호스트·포트·DB명, 팀의 네트워크·TLS 조건, 조회 계정 발급 방식과 별도 비밀 전달 경로 |
| 관계·시간 정의 | 실행/라인/LOT/투입 키/Cell ID/검사 ID/Kit·박스 ID의 유일 범위와 조인 규칙, 발생·기록 시각, 시간대와 정렬 키 |
| 기준 코드·단위 | 외관 G/NG와 PASS/FAIL 대응, 미판정·미계측·실패 사유, 검사 시도와 최종 결정, OCV V 및 IR mΩ 변환, A/B/C의 실제 레인·확인 이벤트 |
| 검증 자료 | 익명 샘플과 기대 누계, 팀 DB가 지원하는 갱신 주기·지연, 샘플 운전의 시작·종료 시각 |

## 같이 정할 사항

1. **재검과 최종 수율.** 최초 FAIL 뒤 재검 대기와 최종 FAIL을 어떻게 구분할지, 최종 결정 시각과 검사 ID를 어느 조회에서 받을지 정합니다. 동일 시각의 병렬 결과는 각 검사 ID로 조회할 수 있어야 합니다.
2. **Buffer 기준값.** A/B/C 레인별 스냅샷과 출입 이벤트 중 어떤 값을 기준으로 쓸지 정합니다. 폐기·이동·재작업과 통신 단절 시 값의 의미를 확인합니다.
3. **Kit 완료와 취소.** 팀의 박스 ID와 SCADA Kit ID 관계, 슬롯·셀 유일성, 완료 상태와 인계의 구분, 취소·재작업 반영 시점을 확인합니다.
4. **수집기 쓰기.** 브리지의 생산자·메일박스 범위, 순번 초기화와 중복키, 지연·정정·충돌 처리, DB 커밋과 ACK, 완료 Kit의 가시성 규칙을 PLC 담당자와 함께 정합니다. 쓰기 계정은 Grafana 조회 계정과 분리합니다. [수집 인터페이스](collector-interface.md)
5. **DB 파일럿.** 선택 실행, 시간 범위, 조회 권한, 갱신 주기, 데이터 신선도와 지연을 스테이징에서 확인합니다. 10초 화면 갱신은 부하 측정을 위한 시작값입니다.

회신에는 `항목 / 제공 데이터 또는 규칙 / 담당 / 미정 사항`을 적어 주세요. 우선 **조회 정의, 키·시간·단위 규칙, 익명 샘플**을 받으면 SCADA 쿼리를 작성할 수 있습니다.

## 공동 인수 기준

| 검증 상황 | 기대 결과 |
| --- | --- |
| 정상 4셀, 같은 특성군 포장 대기 1셀, 외관 FAIL 1셀, 최종 전기검사 FAIL 1셀, 재검 대기 1셀 | ID 8셀, 외관 PASS 7셀·FAIL 1셀, 전기검사 최종 PASS 5셀·FAIL 1셀, 전기검사 최종 미결 1셀, 완료 Kit 1개. 포장 4셀은 슬롯 1–4에서 각각 확인 |
| 위 정상 4셀 중 1셀이 1차 FAIL 후 재검 PASS | 해당 셀의 검사 관측 2건을 모두 조회. 최종 집계는 PASS 1셀 반영 |
| 같은 시각에 서로 다른 레인에서 검사 완료 | 서로 다른 검사 ID와 측정값이 보존되며 각 상세 조회에서 해당 Cell ID 확인 |
| 동일 이벤트 재전송 또는 커밋 직후 연결 종료 | 중복 집계 없이 원 이벤트 1건 유지. 동일 키에 다른 내용이 들어오면 충돌 확인 가능 |
| A 그룹 5셀 대기 중 4셀 포장 | 이벤트나 스냅샷 기준으로 A Buffer 5 → 1셀, 완료 Kit +1. 불완전·혼합 Kit는 완료 누계에 포함되지 않음 |
| 조회 구간 시작 전 데이터, 늦게 도착한 결과, 통신 단절 | 구간 이후 누계에 시작 전 이력 반영. 지연 수신과 미수집은 실제 0과 구분 |
| 두 실행의 상대 순번이 같거나 시간이 겹침 | 실행별 생산량·검사·Kit이 섞이지 않고 각 실행 이력을 개별 조회 |
