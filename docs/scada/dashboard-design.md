# Cellect 2A SCADA 화면 설계

1차 비전 Cell ID 부여 → 2차 비전 외관 PASS/FAIL → 블랙박스 OCV·IR 검사 → A/B/C 특성군 분류 → 같은 특성군 셀 4개 Kit 포장. 외관 FAIL은 별도 배출로 본다. [공정 v2](../2a-data-design.md)의 병렬 검사 4레인, ID 재확인, 재검 및 인계는 조회에 필요한 데이터가 확보되는 순서대로 연결한다. Kit와 공정 문서의 박스 관계는 DB 담당자와 확인한다.

## 화면 구성

| 화면 | Grafana 패널 | 표시 내용과 탐색 경로 |
| --- | --- | --- |
| 공정 개요 | Stat, Bar chart, Time series, State timeline | ID 발급·외관 PASS·전기검사 최종 PASS·그룹 분류·완료 Kit, 시간대별 처리량, 분류별 포장 대기. 셀·Kit·설비 화면으로 이동. |
| Vision | Stat, Bar chart, Table | ID 읽기 실패, 외관 PASS/FAIL·미판정, LOT와 결함 코드별 외관 FAIL. 셀 행에서 Cell ID 이력으로 이동. |
| OCV·IR 검사 | Time series, XY chart, Table | OCV(V), IR(mΩ) 추세와 분포, 두 값의 산점도, 검사기별 검사 건수·실패·시간, 시도별 결과와 재검 회복. 측정값 클릭 시 셀 이력으로 이동. |
| A/B/C 분류 | Bar chart, XY chart, Table | 특성군별 수량, OCV·IR 분포, 예정 특성군과 실제 레인, 미분류·불일치. A/B/C는 전압·저항 유사 특성군으로 표시하고, PASS/FAIL 상태와 색상을 구분한다. |
| Kit 포장 | Stat, Time series, Table | 완료 Kit 수, Kit별 4개 슬롯 및 셀 목록, 특성군, 포장 시간, OCV·IR 범위(최댓값−최솟값), 인계 확인. Kit 행에서 셀 이력으로 이동. |
| 셀 추적 | Table, State timeline | Cell ID 검색. ID·Vision·검사 시도·분류·Kit·인계 이벤트를 발생 시간순으로 조회한다. |
| 설비·데이터 상태 | State timeline, Stat, Table | 설비 상태, 마지막 수신 시각, 통신 단절 구간, 알람 발생·확인·해제 이력. 버퍼 재고는 제공 가능 시 추가한다. |

시작용 대시보드는 개요, 특성군 현황, 완료 Kit, 셀 요약을 구현한다. DB 연결 후 시간 범위, 시연 실행 ID, LOT을 공통 필터로 제공한다. 화면별로 검사기, 특성군, Cell ID, Kit ID를 추가하고 데이터 링크로 관련 화면에 값을 넘긴다. 발생 시각 기준으로 조회하고 시연 화면은 Asia/Seoul로 표시한다. 개요 자동 갱신은 10초부터 검토하고 DB 갱신 주기와 쿼리 비용을 확인해 조정한다.

## 집계 정의 초안

| 지표 | 정의 |
| --- | --- |
| 외관 PASS율 | 외관 PASS 고유 셀 / 외관 PASS·FAIL 판정 완료 고유 셀. 미판정과 ID 읽기 실패는 별도 표시한다. |
| 1차 전기검사 PASS율 | 1차 PASS 고유 셀 / 1차 PASS·FAIL 판정 완료 고유 셀. 재검 결과는 재검 회복 집계에 반영한다. |
| 최종 전기검사 PASS율 | 최종 PASS 고유 셀 / 최종 PASS·FAIL 판정 완료 고유 셀. 검사 중, 재검 대기, 데이터 미수신을 표시한다. |
| 그룹 분류 셀 수 | 실제 진입이 확인된 고유 셀을 A/B/C별로 집계한다. 목표 그룹과 실제 라인 불일치는 상태로 표시한다. |
| 완료 Kit 수 | 완료 이벤트와 동일 특성군 고유 셀 4개, 슬롯 1~4를 대조한다. 불완전·혼합·중복 구성은 별도 집계한다. |
| 그룹 매칭 효과 | 기준선과 실제 Kit의 OCV·IR 편차를 비교한다. 기준선의 투입 순서, 표본 제외 규칙, 편차 요약 방식은 공정·DB 담당자와 합의한다. |

이벤트량은 선택 구간 내 발생 시각을 기준으로 센다. 같은 실행·LOT 코호트의 수율을 비교할 때는 같은 고유 셀 집합에 각 단계 결과를 연결한다. 분모 0, 미수집, 미판정은 화면에 상태로 표시한다. 수율, 지연 알람 및 통신 단절의 임계값은 데이터 주기와 공정 기준 확인 후 설정한다.
