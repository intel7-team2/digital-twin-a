## 목표

제출용 계획서에서 문제 정의, 제안 기능, 비교시험, 채택 기준을 연결한다.
핵심 질문은 **구간별 셀 공급이 순서별 구성보다 전압 편차를 줄이면서 필요한 공급량과 대기시간 조건도 충족하는가**이다.
부적합·보류 재고 차단과 셀·세트 ID 및 인계 수량 일치는 공급 방식과 관계없이 충족할 조건이다.

## 문제가 제대로 다뤄지는가

**설계와 검증의 연결은 갖췄지만, 실제 필요성과 효과는 아직 입증하지 않았다.**
실제 공정에 편차·유출·이력 오류가 관측되었다고 단정하지 않는다. 지금은 아래 설계 가설을 시험하는 계획이다.

| 해결·검증할 문제 | 계획한 대응 | 판단할 증거 | 아직 정할 것 |
|---|---|---|---|
| 합격 셀을 어떤 방식으로 묶어 공급할 것인가 | 순서별 구성과 A/B/C 전압 구간별 구성을 비교 | 같은 입력·순서·관찰 시간에서 세트 편차, 완성 세트 수, 공급률, 대기시간, 잔여 재고 | 실제 수신 공정의 요구 공급량·공급률·허용 대기시간 |
| 측정 실패가 불량 판정이나 정상 공급으로 이어지는가 | 측정 유효성 → 합격 판정 → 구간·세트 편차 확인 | 누락·접촉 실패·기한 초과·상하한 이탈 시나리오 | 셀 사양, 장비, 측정 조건과 허용차 |
| LOT 보류 전에 들어온 재고가 계속 공급되는가 | LOT 상태와 셀 판정을 분리하고 대기 재고·미공급 세트 잠금 | 보류 전후 재고·예약·공급 ID 대조 | 보류·해제 정책의 승인 범위 |
| 통신·DB 지연으로 중복 공급이나 이력 불일치가 발생하는가 | 요청 ID별 물리적 인계와 이벤트 ID별 DB 저장을 분리 | 부분 배출·수신 확인 유실·중복 요청·DB 장애·재시작 시험 | 통신 타임아웃, 기록 보존 장치·범위 |
| 가상 시험과 실물 연계를 혼동하는가 | 사전 데이터 시험과 온라인 연계 목표를 구분 | 셀 ID·상태·수량·시각 일치, 누락·지연 기록 | 실제 동기화 대상과 갱신 주기 |

편차 감소만으로 개선안 채택을 선언하지 않는다. 시험 전에 정한 공급·대기 조건과 공급 차단·ID 일치 조건까지 충족해야 한다.
순서별 공급만으로도 요구조건을 충족하거나 구간별 공급이 과도한 대기·잔여 재고를 유발한다면, 구간별 공급의 추가 필요성을 재검토한다.

## 내일 우선 확인할 것

1. **실제 공급 요구를 확인한다.** 필요한 공급량·공급률·허용 대기시간을 정해야 비교시험의 최종 판정이 가능하다. 수치는 아직 없다.
2. **기준 데이터를 확보한다.** 사용할 셀 모델·사양, 전압 측정 조건·장비, 실측 셀 수를 정하고 순서별 구성의 편차부터 계산한다.
3. **필수 검증과 확장 구현의 우선순위를 정한다.** 수업·장비 가용 시간 안에서 검사 유효성, LOT 재고 차단, 인계 ID·수량 일치 검증을 우선 검토한다. 온라인 연계·DB 자동 복구까지의 구현 범위는 아직 확정하지 않았다.
4. **공용 태그를 확정한다.** 현재 PoC와 4조 명시 주소는 `M0`, `M10`, `M200`, `D200`이 중복된다. 계획서의 전용 영역은 제안이며 프로그램에는 미적용이다. X/Y는 자료 부족으로 비중복 미확정이다.
5. **문서의 요구사항과 구현 현황을 대조한다.** 보강된 예외·복구 규칙은 구현·검증할 요구사항이며, 이미 동작한다고 표시하지 않는다.
