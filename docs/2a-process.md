# 2A 공정 정리 (11/19 기준)

김동혁 님 청사진(ioio.factoryio, 배치만 잡은 상태)과 #dtwin-2a 대화에서 정한 내용. 센서·태그·통신은 아직 안 넣었음.

## 흐름

| 순서 | 공정 | 내용 |
|---|---|---|
| 1 | 투입 + 1차 비전 | 셀 투입. 첫 비전에서 ID 부여(Factory I/O 안에서 임의 UUID 생성, 웹캠 없음). 외관 판정도 이때 같이 |
| 2 | 외관 NG 폐기 | 외관 NG 셀은 기계로 보내지 않음. 본선 끝 슈트 → Remover에서 제거 |
| 3 | 전압·저항 검사 (블랙박스) | Pusher가 빈 기계로 보냄. 기계(Machining Center) 3대 병렬, 입구마다 Roller Stop. 들어갈 때 ID에 전압·저항 값을 임의로 붙이고 기준식으로 등급 계산 |
| 4 | 합류 → 2차 비전 → A/B/C 분류 | 기계 출구가 수집선 하나로 모여 분류선으로 감. 2차 비전은 분류 Pusher 바로 앞. ID로 등급 조회 → 해당 Pusher가 A/B/C 레인으로 밀어냄 |
| 5 | 전압 NG 폐기 | 원래 순환선 재검사 계획이었으나 안 되는 걸로 정리. Remover로 제거. 재검사용 4번째 기계는 빠짐 |
| 6 | 포장 → 2B | 레인마다 Pick & Place가 박스 위에 셀 4개를 올림. 박스째 Remover에 도착 = 다음 공정(2B)으로 넘어감 |

그림 범례: 파랑 = 정상, 초록 = 전압 NG(지금은 폐기), 회색 = 외관 NG(폐기).

## DB에 남기는 값 (셀 1개당)

셀 ID, LOT, 외관 결과, 전압, 저항, 등급, 박스 ID.

## 참고: prj01 (이순필 시험용)

팀 기준 장면은 아님. Pusher·게이트·기계 START·팔레트 적재 동작을 미리 시험해 본 장면.

- 장면: `factoryio/scenes/prj01.factoryio` (생성: `factoryio/tools/build_prj01.py`)
- 시험용 컨트롤러: `plc/testplc_prj01.py` (Modbus TCP 127.0.0.1:502, softplc.py와 같은 방식. 둘을 동시에 켜지 말 것)
- 신호표: `docs/prj01-signals.md` (생성: `factoryio/tools/gen_signal_list.py`)

시험하면서 확인한 것 (ioio에 센서 넣을 때 참고):

- 벨트 속도 0.60 m/s, 원자재 셀 길이 약 0.38 m (센서 기록으로 측정)
- Pusher: 센서가 셀 앞부분에서 켜지므로, 센서 → Pusher 중심 거리 + 셀 절반을 벨트 속도로 나눈 시간만큼 기다렸다 밀어야 함. 밀 때는 이어진 벨트를 같이 세워야 셀이 안 틀어짐
- 스톱 블레이드: 센서가 날보다 앞에 있으면 센서가 꺼져도 셀 꼬리가 날 위에 있음. 날을 0.8초 더 내려 두고 뒤 셀은 앞 벨트를 세워서 붙잡아야 함
- Machining Center: 셀이 입구 베이에 들어와 있을 때 Start 펄스를 줘야 돌기 시작. 로봇이 느려서 투입 → 가공 시작까지 약 16초
- 90도 옆 벨트로 옮겨 탄 셀은 틀어져서 기계 입구 베이에 안 맞음. 샘플(Production Line)처럼 모서리에 Wheel Aligner를 두거나 꺾이는 구간을 줄여야 함
