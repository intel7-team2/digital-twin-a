# Cellect 2A | Factory I/O 제작 계획

기준: 디지털트윈_2A_계획서_v1.0.hwp §2~4. 기존 씬에서 Modbus 입출력과 NG/A/B/C 분류를 관찰했지만 마지막 통합 시험은 이상 정지했고 4셀 인계는 미확인이다.

| 구역 | 만들거나 조정할 부분 | 검증 기준 |
|---|---|---|
| Z1 입고 | 기존 Emitter·도착 센서·비전 유지. 파랑/초록/금속은 LOT이며 등급은 별도 | 도착 1회에 ID 1개. 비전 1/4/7 판독. 셀이 있을 때 0이면 미판독 |
| Z2 검사 | 검사 블레이드와 센서 위치·극성 확인. 전압·저항은 PLC 데이터로 연결 | 세 재질 모두 정지·해제. 목적지 여유와 분류 구간 확보 전에는 해제 금지 |
| Z3 NG | 푸셔 앞 센서·슈트·회수기 정렬 | 값 없음·기준 이탈·미판독은 격리. 같은 LOT NG 3건이면 적재된 셀도 공급 차단 |
| Z4 버퍼 | A부터 닫힌 게이트 앞에 4개 적재 후 B/C 반복 | 실제 진입과 재고 일치. 4개가 분기점을 막지 않고 5번째는 대기 |
| Z5 인계 | 합류 높이와 출구 빔 조정, 2B 준비·수신 확인 모의 신호 연결 | 준비 OFF면 0개. 준비 ON에서 한 레인만 방출, 빔 ON/OFF 4쌍과 해당 세트 수신 확인 뒤에만 다음 세트 허용 |

첫 제작 대상은 A 레인 4셀 인계다. 셀이 붙어 센서가 한 번만 켜지면 게이트와 벨트로 간격을 먼저 만든다. 실패 시 분리 게이트를 검토한다. 푸셔 복귀만으로는 실제 레인 진입을 보증할 수 없으므로 영상과 예약·재고 기록을 비교하고 필요 시 입구 센서 3점 추가를 합의한다. 기본 수량은 벨트 6, 푸셔 4, 블레이드 4, 위치·출구 센서 7, 비전 1, Emitter 1, 슈트·Remover 각 2, 조작반 1식이다.

PLC는 셀별 ID·LOT·전압과 레인별 순서를 추적하고 출고 직전 보류 LOT를 재검사한다. 보류 셀이 섞인 레인은 잠그고 격리·재개 절차를 합의한다. 2A→2B는 공급 요청·세트 ID, 2B→2A는 준비·수신 확인. SCADA는 출구 기록과 해당 세트의 셀 ID 4개를 대조한다.
